# Security Policy

## Reporting

Report suspected vulnerabilities through GitHub private vulnerability
reporting on this repository. Do not put credentials, identity files, private
host data, or undisclosed vulnerability details in a public issue.

## Security model

The [public security guide](docs/user/security.md) explains the caller trust
boundary and residual risks. Test-backed guarantees live only in the
[security contract](docs/contracts/security.md), with review procedures in
[security maintenance](docs/maintenance/security.md).
